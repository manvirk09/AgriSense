Extract the ZIP, then upload the files inside it to the root of the `AgriSense` repository.

## Local live Wokwi mode
1. Start Wokwi with the ESP32 project.
2. Run `START-BRIDGE.bat`.
3. Run `START-DASHBOARD.bat`.
4. Open `http://127.0.0.1:8080`.

The public GitHub Pages copy can show dashboard/demo data. Live Wokwi data through `127.0.0.1:8787` works on the same computer where the bridge is running.
